# 🦷 Sakthi Dental Clinic — Official Website

A modern, responsive and professional dental clinic website designed for **Sakthi Dental Clinic, Hosur**.

The website provides patients with a clean and welcoming digital experience to explore dental services, learn about the clinic, view facilities, read patient experiences, access FAQs and get in touch with the clinic.

---

## 🌐 Project Overview

**Sakthi Dental Clinic** is a frontend web development project created as part of the **ShadowFox Virtual Internship — Intermediate Project**.

The website focuses on delivering:

- 🦷 Professional dental-care presentation
- 👨‍⚕️ Clinic and doctor information
- 🏥 Dental treatment services
- 🏢 Clinic facilities
- 💬 Patient testimonials
- ❓ Frequently asked questions
- 📞 Contact and appointment information
- 📱 Responsive design across devices
- ✨ Modern and patient-friendly user interface
